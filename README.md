# 🤖 AI Real-Time Facial Analytics

A modern, real-time desktop application built with Python for facial analysis, emotion tracking, and automated data logging.

✨ Features
- **Real-Time Emotion Detection:** Accurately detects and analyzes facial expressions in real-time using advanced AI models.
- **Automated Data Logging:** Automatically saves session records and analytics data into structured CSV logs.
- **Modern UI:** Built with **CustomTkinter** for a sleek, responsive, and dark-mode friendly user interface.
- **Lightweight & Fast:** Optimized using **OpenCV** and **DeepFace** for smooth video processing.

⚙️ How It Works (Working)
1. **Webcam Feed Capture:** The application initializes your webcam using **OpenCV** to stream live video frames.
2. **AI Facial Analysis:** Every captured frame is processed through **DeepFace** to detect faces and analyze dominant emotions (e.g., happy, sad, neutral, angry, etc.).
3. **Interactive UI Display:** **CustomTkinter** renders a clean dashboard showing the live video feed alongside real-time analytical metrics.
4. **Data Logging:** Key detection events and analysis results are dynamically logged into a CSV file for future tracking and evaluation.

🛠️ Tech Stack
- **Language:** Python
- **GUI Framework:** CustomTkinter
- **Computer Vision:** OpenCV
- **Facial Analysis AI:** DeepFace
- **Data Handling:** Pandas / CSV
